# 📚 電子書章節工具箱（eBook Chapter Toolkit）

> **🌐 [點此開啟網站](https://suyanali.github.io/eBook-Chapter-Toolkit/)**  
> 網址需在儲存庫的 **Settings → Pages** 啟用後才會生效。設定方法見下方「發布網站」。

不必安裝軟體、不必註冊的電子書章節工具，支援 **EPUB / HTML / TXT**。適合 AO3 等連載小說的更新流程：先從完整下載檔擷取新章節，翻譯後再追加回原有電子書。也能比較新舊版本，或整理 AI 翻譯後不一致的章節標題。

**隱私：** 檔案只在瀏覽器本機處理，不會上傳小說，也不會保留作品的更新歷史。

## 🚀 第一次使用：我該點哪個分頁？

| 分頁 | 適合的情況 | 需要的檔案 |
|---|---|---|
| **章節擷取** | 全書有 1～15 章，但只想取 13～15 章 | 最新 EPUB / HTML / TXT |
| **版本比對** | 不記得上次下載到哪一章 | 舊版 + 新版 |
| **章節合併** | 第 13～15 章已翻譯，要接回舊書 | 舊的完整書 + 新增章節 |
| **章節整理** | AI 把「Chapter 13」「第十三章」翻得不統一 | TXT 或 HTML |

這四個功能**彼此獨立**，可以只使用其中一個，不必先建立紀錄或 JSON 檔案。

## ✂️ 教學一：擷取指定章節（不用舊檔）

**範例：** AO3 下載一本包含第 1～15 章的 EPUB，只需要第 13～15 章去翻譯。

1. 開啟網站，點 **「章節擷取」**。
2. 在 **「來源檔」** 選取 EPUB、HTML 或 TXT，點 **「辨識章節」**。
3. 看下方章節清單，先按 **「取消全選」**，再勾選第 13、14、15 章。也可以在範圍框輸入 `13-15`，按 **「選取範圍」**。
4. 想取最後三章，可以輸入 `last:3`；想取不連續章節，可輸入 `13,15,18`。
5. 選擇 **輸出格式 EPUB、HTML 或 TXT**。需要每章分開輸出，可勾選 **「每章獨立輸出 ZIP」**。
6. 點 **「輸出檔案」**，下載後交給翻譯工具即可。

每章旁的「預覽」可檢查擷取內容是否正確。不同來源的章節結構不一定一致，請先確認章節清單。

## 🔍 教學二：版本比對（找出新增章節）

**範例：** 舊中文版有第 1～12 章，最新下載的原版有第 1～15 章。

1. 點 **「版本比對」**。
2. 在 **「舊檔」** 選舊書，在 **「來源檔」** 選新下載的完整書。
3. 按 **「辨識章節」**。
4. 程式會根據**章節編號**嘗試勾選新增章節，請自行確認勾選範圍。
5. 選擇 EPUB / HTML / TXT，按 **「輸出檔案」**。

**注意：** 這不是逐字差異比對。作者修改舊章節、在中間插入章節，或翻譯把標題改得難以辨認時，結果可能不準，需人工確認。

## ➕ 教學三：把已翻譯的新章節合併回舊書

**範例：** 原本閱讀中的中文版是第 1～12 章，現在已翻譯好第 13～15 章。

1. 點 **「章節合併」**。
2. 在 **「舊檔」** 選原本正在閱讀的完整小說（主檔）。
3. 在 **「新增章節檔」** 選翻譯完成的新章節。可以多選 EPUB、HTML、TXT，也可以混用。
4. 按 **「辨識章節」**，確認只有需要新增的章節被勾選。
5. 用章節旁的 **「↑」** 調整順序；如需統一標題，可選標題格式再按 **「套用標題整理」**。
6. 點 **「輸出檔案」**。**先用閱讀器開啟新檔，檢查內容、圖片及目錄**，確認後再替換舊檔。

### 合併輸入與輸出格式

輸出格式固定**跟隨舊檔（主檔）**：

| 舊檔 | 新增檔可使用 | 輸出 |
|---|---|---|
| EPUB | EPUB / HTML / TXT | **EPUB** |
| HTML | EPUB / HTML / TXT | **HTML** |
| TXT | EPUB / HTML / TXT | **TXT** |

例如「舊 TXT + 新 EPUB」會輸出 TXT；「舊 EPUB + 新 TXT」會輸出 EPUB。輸出 TXT 時，**圖片、粗體、斜體與樣式會消失**。

程式不會直接覆蓋原書，請先備份，再手動將合併的新檔取代舊檔。

## 📝 教學四：整理 AI 翻譯後的章節標題

**範例：** TXT 同時出現「第一章」「第 2 章」「Chapter 3」，讓閱讀器的目錄不一致。

1. 點 **「章節整理」**，匯入 TXT 或 HTML。
2. 按 **「辨識章節」**，檢查章節清單。
3. 在 **「標題格式」** 選擇統一的形式，例如「第13章」。
4. 如果匯入的是全書第 13～15 章，可將 **「重新編號起點」** 設為 `13`。
5. 點 **「套用標題整理」**，確認標題後按 **「輸出檔案」**。

**TXT 自訂章節規則（Regex）** 是進階選項，新手可以留空。EPUB 內部原結構的標題整理目前尚不支援。

## 📱 手機安裝與離線使用

使用手機瀏覽器開啟網站，從瀏覽器選單選擇 **「安裝應用程式」** 或 **「加入主畫面」**。第一次需連線載入網站及程式檔案；完成快取後，可嘗試離線使用。不同瀏覽器的選單名稱可能不同。

## 💻 Windows 本機測試

1. 在本專案 GitHub 頁面選 **Code → Download ZIP**。
2. 解壓縮後進入包含 `index.html` 的資料夾。
3. 電腦已安裝 Python 的話，直接雙擊 **`Start.bat`**。
4. 瀏覽器開啟 **[http://localhost:8000](http://localhost:8000)** 即可使用。
5. 使用完畢，關閉黑色命令視窗；PowerShell 可按 `Ctrl+C` 停止。

也可以在資料夾直接執行：

```powershell
py -m http.server 8000
```

更新後若看到舊畫面，先按 `Ctrl+F5`。PWA 快取尚未更新時，可關閉網站重新開啟，必要時清除網站資料。不建議直接雙擊 `index.html` 來測試 PWA 功能。

## 🌐 發布網站（GitHub Pages）

專案維護者第一次上傳後，前往 GitHub 儲存庫：

1. 點 **Settings → Pages**。
2. 在 **Build and deployment** 的 **Source** 選 **Deploy from a branch**。
3. **Branch** 選 **main**，資料夾選 **/ (root)**，點 **Save**。
4. GitHub Pages 部署成功後，網站網址就是 **https://suyanali.github.io/eBook-Chapter-Toolkit/**。

這是純靜態網站，不需要 GitHub Actions、自行架伺服器或額外編譯。

## ⚠️ v0.2 已知限制

- **EPUB 目錄跳轉：** 某些 EPUB 合併後，新增章節的目錄連結可能跳回閱讀進度 0%／書籍開頭。
- **EPUB 排版與圖片：** 新增 EPUB 章節會嘗試保留 XHTML 與來源資源，但特殊 CSS、字型、SVG、跨章節連結尚未完整測試。
- **HTML 外部圖片：** 不會從外部網站自動下載圖片。
- **TXT：** 只保留文字；支援 UTF-8 及帶 BOM 的 UTF-16。
- **閱讀器書籤：** 沿用檔名也不能保證靜讀天下或其他閱讀器的進度、書籤完全不變。
- **標題辨識：** 翻譯後的標題差異過大時，可能需要手動修改。

**請務必保留原檔備份，並在替換舊書前測試新增章節、圖片及目錄跳轉。**
