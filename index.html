操作說明（各分頁）

章節擷取

選擇 EPUB、HTML 或 TXT → 辨識章節 → 勾選所需章節（例如 13-15 或 last:3）→ 選擇輸出格式 EPUB、HTML 或 TXT → 輸出。勾選每章獨立輸出會下載 ZIP。

版本比對

選擇舊檔及最新檔（格式可不同）→ 辨識章節 → 檢查自動勾選的新章節 → 選擇輸出格式 → 輸出。依章節編號比對，未編號或插入章節須人工確認。

章節合併

舊檔：單一 EPUB、HTML 或 TXT。來源檔：可多選 EPUB、HTML、TXT，亦可混用。輸出格式固定跟隨舊檔。

選檔 → 辨識 → 勾選新增章節 → 用 ↑ 調整順序 → 如需統一標題，選格式後按套用標題整理 → 輸出。預設沿用舊檔名，不會直接覆蓋。先備份再替換閱讀器內的檔案。

章節整理

匯入 TXT 或 HTML → 辨識 → 勾選需修改的標題 → 選格式（例如第13章）→ 可指定起始編號 → 套用標題整理 → 輸出。EPUB 原結構標題整理尚不支援。預覽可檢查正文，分割以字元位置操作，會失去該段原排版。

格式限制

TXT 支援 UTF-8、UTF-16 BOM。EPUB 新章節保留 XHTML 與來源資源；複雜跨章連結、字型、特殊 CSS 尚待驗證。HTML 外部圖片不會自動下載；EPUB 轉 HTML 嘗試內嵌本地圖片，但不保證完整 CSS。輸出 TXT 必然失去圖片及樣式。
